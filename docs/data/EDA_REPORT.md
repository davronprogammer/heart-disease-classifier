# EDA Report

## 1. Dataset Overview

This report summarizes reproducible exploratory analysis of the Heart Failure Prediction Dataset for this project's binary heart disease classification task. The target is HeartDisease: 0 = Normal and 1 = Heart disease. The analysis is observational and does not make medical diagnoses.

## 2. Dataset Dimensions

The raw file at ml/data/raw/heart.csv contains 918 observations, 12 columns, 11 input features, and the HeartDisease target.

## 3. Data Quality

The dataset has a consistent observed categorical schema. Important numeric values still require contextual review: especially Cholesterol = 0 and RestingBP = 0.

## 4. Missing Values

The dataset contains 0 NaN cells. This does not mean all values are semantically complete: numeric zeros can still represent suspicious or unrecorded values.

## 5. Duplicate Analysis

No duplicate rows were found.

## 6. Suspicious Values

| Feature | Finding | EDA interpretation |
| --- | --- | --- |
| RestingBP | 1 zero | Suspicious/invalid; requires a preprocessing decision. |
| Cholesterol | 172 zeros | Suspicious and potentially unrecorded; no imputation has been selected. |
| Oldpeak | 368 zeros | Not automatically invalid. |
| Oldpeak | 13 negative values, from -2.6 to -0.1 | Requires contextual investigation; do not remove automatically. |

## 7. Target Distribution

| Class | Count | Percentage |
| --- | ---: | ---: |
| Normal (0) | 410 | 44.66% |
| Heart disease (1) | 508 | 55.34% |

The target is moderately imbalanced, not severely imbalanced. This should be considered in model evaluation.

## 8. Numerical Feature Findings

Age has a mean of approximately 53.5 years. RestingBP is concentrated around 120-140 for many records, MaxHR commonly falls around 120-160, and the Cholesterol distribution is strongly affected by its zero values. Oldpeak includes both zero and negative values, which are retained for analysis.

## 9. Categorical Feature Findings

The observed categories matched the expected sets for Sex, ChestPainType, FastingBS, RestingECG, ExerciseAngina, and ST_Slope. Notable observed counts include Sex: M = 725 and F = 193; ChestPainType: ASY = 496; RestingECG: Normal = 552; ExerciseAngina: N = 547; and ST_Slope: Flat = 460.

## 10. Feature-Target Relationships

Within this dataset, ASY ChestPainType and ExerciseAngina = Y show higher observed HeartDisease occurrence than their comparison categories. These are associations, not causal or statistically significant claims.

## 11. Correlation Findings

The strongest reported numerical associations with HeartDisease are approximately +0.40 for Oldpeak, +0.28 for Age, and -0.40 for MaxHR. Correlation does not imply causation, and low pairwise correlation does not make a feature unhelpful for a model.

## 12. Outlier Findings

IQR screening flagged 183 Cholesterol, 214 FastingBS, 28 RestingBP, 16 Oldpeak, and 2 MaxHR observations. The FastingBS count needs special interpretation because it is binary; Cholesterol flags are strongly affected by zero values. Statistical flags are screening results, not proof of bad records.

## 13. Important EDA Insights

- No NaN values and no duplicate records were found.
- Cholesterol = 0 is the largest data-quality issue by count.
- The single RestingBP = 0 record needs an explicit preprocessing decision.
- Negative Oldpeak values require context, rather than automatic deletion.
- Oldpeak, MaxHR, Age, ChestPainType, and ExerciseAngina appear potentially informative for classification.

## 14. Preprocessing Recommendations

Do not apply these in EDA. The preprocessing stage should decide how to treat Cholesterol = 0 and RestingBP = 0, investigate negative Oldpeak values, select categorical encoding and numerical scaling, define an outlier strategy, use a leakage-safe train/validation/test split, and account for the moderate target imbalance during evaluation.

## 15. Final EDA Conclusions

The dataset is structurally ready for the next analytical stage but is not simply declared clean. Its 918 records have no NaN values or duplicates, while suspicious zeros, negative Oldpeak values, and IQR flags require documented preprocessing decisions. The EDA identifies potentially useful feature-target associations without making causal or clinical claims.
